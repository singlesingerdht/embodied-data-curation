# 可认领的协作任务

公共契约、判断语义、算法方法及发布范围由核心维护者审查。每人使用独立分支和 PR，并写明所改输入／输出属于使用者端、算法端还是阶段交接。

| 优先级 | 任务 | 当前基础 | 可验收的下一步交付 |
|---|---|---|---|
| P0 | 打包与迁移 | CPU 包裁剪、文件哈希清单和独立安装验证 | 维护 Python 版本 CI、依赖锁定策略、许可清单和迁移差异审查 |
| P0 | 输入契约 | 逻辑名统一绑定、SI 语义门槛 | 更多后端相同输入的契约对照；坐标系／字段语义的显式声明与失败提示 |
| P0 | 工作流 | 有限阶段、子集、放行和恢复 | 更多分支／失败恢复场景；优化全量哈希开销，保持失效准确性 |
| P0 | 时间适配 | 三项 CPU 方法消费显式仿射 clock 映射 | 更多真实设备映射验证、误差证据和有效区间；不自动猜共同时钟 |
| P0 | 变换接口 | identity 行映射验证及合成编辑／增强 | 为一种明确的裁剪／重采样方法设计非 identity 契约与验收；不得伪造来源 |
| P1 | 复核与展示 | 追加复核 CLI、工作流和固定报告 | 可点击帧证据、复核差异展示及平台接口；不覆盖原评分 |
| P1 | SDK 教程 | 四类插件与 reader 模板 | 独立包教学、错误示例、数据注册录屏和 README 示例维护 |
| P1 | 测试与发布 | CPU 回归、工作流边界及打包验证 | 资源／耗时统计、官方 LeRobot 固定版本 CI、支持矩阵与发布清单 |
| P2 | 真实方法 | 值／编辑／增强只验接口示例 | 每次引入一个方法，独立核对数据、模型、输出、收益和许可 |

不要一次把所有研究算法搬入基础包；真实方法原输出不被压成统一价值分。家庭任务、VR 数据形态与加速方式需要现场确认；视频修复仅收集需求与问题样例。
