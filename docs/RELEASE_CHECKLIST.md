# 来源、许可与发布清单

当前为私有协作基线。没有发现已确认的仓库级分发许可，因此不添加或宣称 MIT／Apache 授权。此页是待办与边界，不能代替权利方确认。

| 对象 | 本轮处理 | 转公开前仍需核查 |
|---|---|---|
| 框架自有代码 | 按工作区清单迁移并新增工作流 | 权利归属、贡献者授权、仓库级许可证 |
| 9 项 CPU 算法 | 保留原目录 ID、方法、公式和阈值 | 各算法来源及可再分发条件，尤其保留参考来源的代码 |
| NumPy／PyYAML 与 formats extras | 通过依赖安装，不复制第三方源码 | 发布时固定版本的许可清单／NOTICE及依赖供应链 |
| 官方 LeRobot | 可选依赖，固定验收版本 0.6.1 | 上游及其依赖的分发条件；不把 optional 的训练依赖放入基础包 |
| 第三方子模块／GPU 方法 | 未迁移 | 将来按方法核查；不把未迁 GPU 工具当成已支持 |
| 模型权重／私有 wheel | 未迁移且基础安装不依赖 | 下载、使用、再分发许可及可用性 |
| 真实机器人数据／历史结果 | 未迁移 | 数据来源、授权、隐私、分发范围和证据公开许可 |
| 合成示例 | 代码生成，无真实示教 | 明确标注 synthetic，不宣称实际修复、估值或训练收益 |

迁移基线记录源 Git HEAD 和**工作区文件哈希**，含必要未跟踪文件，见 [source-manifest.json](migration/source-manifest.json)。它用于溯源，不表示清单里的文件全部原样进入新库；适配、测试夹具和文档的变更与排除另记迁移报告。

验收命令与结果见 [STATUS](src/edc/STATUS.md)。远端建立后先确认 private；转公开必须单独核查并明确授权。
