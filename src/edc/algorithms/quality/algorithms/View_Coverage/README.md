# 拍摄视角覆盖（View_Coverage）

第一版只查镜头污渍。每路 RGB 相机均匀抽 30 帧，逐像素找满足三个特点的暗斑：每帧都在（90% 以上的帧偏暗）、中心浓往外变淡且边缘发虚、8 个方向都变淡（圆的一团，排除桌边长条阴影）。中心比周围暗 `min_dark`（默认 0.2）以上判复核，附位置、暗度和红框证据图（开头、中间、结尾 3 帧）。只用 CPU，不需要模型。

## 运行

作为第十项内置质量算法，`edc run` / `edc batch` 默认就会跑；单独跑：

```bash
edc run /path/to/episode.mcap --robot configs/robots/x1pro_mcap.yaml --algorithm View_Coverage --output /path/to/results
```

参数写在机器人 yaml 的 `checks.View_Coverage`：`frames`（每路抽几帧，默认 30）、`min_dark`（默认 0.2）、`channels`（只查哪些相机）。

## 局限

- 24 条污渍全部来自同一任务、同一天、同一块污渍，阈值只在这一个例子上定过。
- 桌布上固定不动、边缘发虚的深色污点会被当成镜头污渍。
- 操作出画、相机没对准暂不检查。
